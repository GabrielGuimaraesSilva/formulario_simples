# Formulário de Cadastro

Este é um pequeno projeto de formulário de cadastro desenvolvido para praticar HTML e CSS. O objetivo é aprimorar minhas habilidades em estilização de formulários e organização de layouts.

## 📌 Tecnologias Utilizadas

- **HTML5**

- **CSS3**

## 🎨 Estilização

O formulário conta com:

- 📌 Inputs estilizados com bordas e sombras personalizadas.

- 🖱️ Um botão com efeito de pressionamento.

- 🎨 Um fundo gradiente para melhorar a aparência visual.

- 📱 Layout responsivo e centralizado na tela.

## 💻 Estrutura do Projeto

/
├── index.html  # Estrutura do formulário
├── style.css   # Estilos aplicados ao formulário
└── README.md   # Documentação do projeto
